## 1. 운동 중 순서 변경 · 대체 운동 · 슈퍼세트

**순서 변경** — `src/workout-features.mjs`

- `moveItem(list, from, to)`: 배열 항목을 한 자리 옮기는 공통 함수. 범위를 벗어나면 원본 유지.
- `moveExercise(session, exerciseId, direction)`: 세션의 종목 배열에서 위(−1)·아래(+1)로 이동.
  `superset` 표시는 종목 객체에 붙어 있으므로 함께 따라갑니다.
- `exercisePosition(session, id)`: 집중 운동의 `n / m 운동` 표기가 이동 후에도 실제 순서를 따릅니다.

**대체 운동** — `substitutionCandidates(exercises, current, session, {limit})`, `replaceExercise(session, id, replacement, history)`

- 같은 `muscle` +4, 같은 장비 +1, 주동근이 겹치면 +2, 보조근이 주동근과 겹치면 +1로 점수를 매겨 정렬합니다.
  이미 세션에 들어간 종목과 자기 자신은 제외하고, 근력 운동은 근력 종목만 후보로 둡니다.
- 교체 시 세트 수·종류·메모는 유지하고 `done`을 풀며, 새 종목의 직전 기록(`previousSets`)이 있으면 세트 순서대로
  중량·횟수를 채웁니다. 기록이 없으면 중량 0·10회에서 시작합니다.

**슈퍼세트** — `toggleSuperset(session, id)`, `supersetLabel`, `supersetGroups`, `nextExercise`

- 종목을 앞(없으면 뒤) 종목과 묶고 `superset: 'A'`처럼 표시합니다. 다시 누르면 풀립니다.
  한 묶음에 남는 종목이 하나가 되면 표시도 지웁니다(최소 2종목 유지).
- `nextExercise`는 같은 묶음 안에서 아직 미완료 세트가 있는 다음 종목을 먼저 고르고, 묶음이 끝났으면 목록 순서로 넘어갑니다.
- `src/App.tsx`의 집중 운동은 `focusId` 상태를 두고, 슈퍼세트 종목에서 한 세트를 마치면 같은 묶음의 다른 종목으로
  자동 전환합니다(번갈아 진행). `onNext`도 `nextExercise`를 씁니다.
- 화면: 전체 목록 카드의 `순서 위로 / 순서 아래로 / 대체 / 슈퍼세트(해제) / 원판` 버튼과 `슈퍼세트 A` 배지,
  집중 운동의 `↑ 순서 위 · ↓ 순서 아래 · 대체 운동 · 슈퍼세트 묶기/풀기` 버튼.

**테스트** — `tests/workout-features.test.mjs`

- 이동 경계, 슈퍼세트 묶기/풀기/한쪽 해제, 같은 묶음 번갈아 다음 종목, 대체 후보의 부위 우선·중복 제외,
  교체 후 세트 수 유지·완료 초기화·직전 기록 채우기.

## 2. 세트별 직전 기록 인라인 표시

- `previousSets(history, exerciseId)`(기존 `core.mjs`)를 `previousHints`로 감싸 세트 순서대로 돌려줍니다.
- 전체 운동 목록: 각 세트 번호 아래 `이전 60 kg × 10`을 표시합니다(`src/App.tsx`, `previousSets(state.history, e.id)?.sets[i]`).
- 집중 운동: 입력 필드 아래와 세트 목록 각 줄에 `이전 …`을 표시합니다(`src/ui-v2/FocusedWorkout.tsx`의 `hint(set)`).
- 표시 단위는 화면 단위(kg/lb)로 변환하고 저장 값은 kg 그대로입니다.

**테스트** — 직전 세션의 세트 배열과 다른 종목의 `null` 반환.

## 3. 종목별 성장 그래프 & PR 배지

**로직** — `src/workout-features.mjs`

- `exerciseGrowth(history, id, limit)`: 완료 세트가 있는 세션만 시간순으로 추정 1RM·세션 볼륨·세트 수를 만듭니다.
  볼륨은 워밍업을 뺀 완료 세트의 `중량×횟수` 합입니다.
- `personalBest(history, id)`: 기존 `bestOneRm`(Epley, 12회 이하)을 소수 한 자리로 정리.
- `historyPrFlags(history)`: 완료 세션을 시간순으로 훑어 종목별 최고 1RM을 갱신합니다. 첫 기록은 `first: true`,
  이전 최고를 넘은 경우만 PR 배지 대상(`first: false`)입니다.
- `sessionSummary(history, session, goal, reference)`: 직전 세션 대비 볼륨 증감, PR, 세트·분, 주간 목표 진행률.

**화면** — `src/App.tsx`의 `progress()`

- `종목 성장 그래프`: 최근 8종목 칩 → 선택한 종목의 `추정 1RM / 볼륨` 전환, `LineChart`(최대 12세션),
  최고 1RM과 그 세트(중량×횟수·날짜) 표시.
- 운동 히스토리 각 줄에 `PR <종목>` 배지.
- 운동 완료 알림에 `PR …`과 `이번 주 n/m회`를 함께 표시합니다.

**테스트** — 성장 그래프 순서·볼륨·1RM 계산, 첫 기록/동일 기록/갱신 구분, 요약의 증감·PR·주간 진행률.

  `validateSession`은 기존처럼 `rpe`가 있을 때만 1~10을 검사하므로 예전 기록·백업과 호환됩니다.

## 8. 중량·횟수 빠른 조절

- `src/ui-v2/FocusedWorkout.tsx`: 중량 입력 양옆 `− / +`는 kg에서 2.5, lb에서 5씩( `massStep(unit)` ),
  횟수는 ±1씩 조절합니다. 0kg·1회 아래로 내려가지 않습니다.
- 접근성 라벨: `중량 2.5 줄이기/늘리기`, `횟수 1 줄이기/늘리기`.
- 테스트로 `massStep`의 kg/lb 값을 고정했습니다.

## 9. 집중 운동 세트 목록 터치

- 아래 세트 줄은 `Pressable`입니다. 미완료 세트를 누르면 그 세트로 이동해 입력·완료할 수 있고,
  완료 세트를 누르면 값이 입력 칸에 올라와 바로 고칠 수 있습니다(`세트 저장`으로 저장).
- 세트를 완료하면 자동으로 다음 미완료 세트로 넘어갑니다(`doneKey` 효과). 사용자가 완료 세트를 직접 누를 때는
  자동 이동하지 않아 수정 중인 세트가 바뀌지 않습니다.
- `n번째 세트` 제목과 `현재 세트 중량 kg`, `현재 세트 반복 횟수` 라벨은 기존 자동화와 호환됩니다.
