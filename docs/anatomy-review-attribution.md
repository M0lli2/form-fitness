# Form anatomy review mesh

This is an experimental posed model evaluated in GitHub Actions.

The continuous surface and skeletal skinning originate from [Innerscene's Male base mesh – Rigged A-pose](https://www.innerscene.com/tools/library/3d-parts/male-base-mesh-3d-person-rigged-a-pose-380e6d89), adapted from MakeHuman CC0 assets (CC0 1.0). The outer torso and leg contour offsets and muscle labels use [Charleeh's Écorché](https://github.com/Charleeh/ecorche) (CC BY-SA 4.0).

Écorché incorporates BodyParts3D, © The Database Center for Life Science (CC BY 4.0), and Z-Anatomy by Gauthier Kervyn and contributors (CC BY-SA 4.0). Form changes include cross-section sampling, continuous-surface transfer, muscle-region tagging, and matte display materials. The resulting review GLB, as adapted material, is [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
