# 개인정보 처리 구현 설명 (출시 전 초안)

FORM은 사용자가 입력한 운동·체성분과 선택한 결과지 사진을 기기에 보관합니다. 건강 연결을 선택한 경우 OS 권한을 통해 걸음 수, 심박수, 운동, 체중, 체지방을 읽고 선택한 기록을 저장합니다.

건강 데이터를 광고 목적으로 이용하거나 제3자 서버에 전송하는 구현은 없습니다. 휴대폰과 페어링된 워치 사이에는 운동 진행 정보와 완료 이벤트를 전송합니다. 앱 데이터 삭제는 설정에서 가능하며 이미 외부 건강 저장소에 내보낸 데이터는 해당 OS 건강 앱에서 별도로 관리합니다.

JSON 백업은 평문이므로 공유 대상과 저장 위치를 사용자가 선택해야 합니다. 사진은 백업에 포함되지 않습니다.

배포 전 실제 운영 주체, 문의처, 보관 정책, 삭제 정책, 배포 지역 요구사항 및 공개 개인정보처리방침 URL을 확정해야 합니다. 현재 문서를 법적 검토 또는 스토어 심사 완료로 간주하지 않습니다.
