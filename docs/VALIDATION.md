## 로컬 확인

- 도메인 테스트 11개 통과: 빈 세션 방지, 볼륨/1RM, 인바디 검증, 이전 기록 복원, 워치 중복 이벤트, 백업 검증, 주간 경계.
- TypeScript/TSX/JS 구문 검사: 오류 0 (로컬 설치된 TypeScript parser 사용).
- JSON 파싱, Swift/Kotlin 브리지 함수 이름, 휴대폰·워치 앱 ID 계약 검사 통과.

- npm 의존성 설치 및 전체 타입 검사: 이 환경에서 registry.npmjs.org DNS 해석 실패.
- Android/iOS/watchOS/Wear OS 네이티브 컴파일: SDK/Xcode 없음.
- 실기기 접근성, 키보드, Dynamic Type, OS Liquid Glass, 화면 회전, 성능.
- 건강 권한 거부·부분 허용·철회, 실제 건강 데이터 읽기/쓰기.
- 워치 서명·페어링·오프라인 전송·운동 중 프로세스 종료 복구.
