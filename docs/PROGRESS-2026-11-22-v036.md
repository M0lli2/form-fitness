# Form 0.3.6 작업 기록 — UI/UX 밸런스·통일성 (2026-11-22)

모리 님의 지시("배치, 텍스트, 구성등 밸런스와 통일성있게 갖추고 완성도를 높혀봐")로
0.3.5 화면 전체를 디자인 시스템(`src/ui-v2/tokens.ts`, `src/ui-v2/Primitives.tsx`) 기준으로 다시 점검하고
배치·타이포·컴포넌트 규격을 하나로 모은 릴리스입니다. 나중에 ChatGPT 등 다른 도구로 이어서 작업해도
누락이 없도록 무엇을 왜 어떻게 바꿨는지 파일·컴포넌트·접근성 라벨 단위로 남깁니다.

- 기준 커밋: `main` `943f2a4` (v0.3.5)
- 릴리스 브랜치: `release/v0.3.6`
- 새 파일: `src/ui-v2/Icons.tsx`(모노크롬 탭 아이콘), `src/ui-v2/Controls.tsx`(Pill·Segmented·MetricTile·GoalProgress)
- 바뀐 핵심 파일: `src/ui-v2/tokens.ts`, `src/theme.tsx`, `src/App.tsx`, `src/ui-v2/FocusedWorkout.tsx`,
  `src/ui-v2/PlateCalculator.tsx`, `src/WeeklyVolume.tsx`
- 새 네이티브 의존성: **없음**. `react-native-svg` 등을 추가하지 않고 아이콘·그래프·진행 바를 모두 `View`로 그립니다.

## 0. 원칙 — 값은 tokens.ts 한 곳에서만 나온다

`src/ui-v2/tokens.ts`

- `colors`: `accentSoft`를 추가하고 `src/theme.tsx`의 팔레트(`bg·ink·muted·solid·line·accent·accentBase·soft·danger`)를
  전부 이 값에서 파생시켰습니다. 이전에는 두 파일에 거의 같은 색이 따로 적혀 있어 한쪽만 고치면 어긋났습니다.
- `typeScale`: 6단계 + 보조 2단계로 정리했습니다. `title 30 / heading 22 / subheading 18 / body 17 / label 15 / caption 13 / micro 11 / metric 36`.
  화면에서 `11~13` 사이 임의 크기를 새로 만들지 않고 `micro`·`caption`을 씁니다.
- `geometry`: `screenPadding 20, cardRadius 20, innerRadius 14, buttonRadius 16, chipRadius 999, controlMinHeight 52, chipHeight 36, gap 12, sectionGap 16`.
  카드 안 카드(중첩 서브카드)는 `innerRadius 14`, 대형 CTA와 일반 버튼은 `buttonRadius 16`을 공유합니다.

`src/theme.tsx` (기존 화면이 쓰는 얇은 래퍼)

- `palettes`를 `paletteOf(mode)`로 만들어 tokens의 색을 그대로 옮깁니다(색 중복 정의 제거).
- `Glass`(카드) 반경 21 → **20**, 패딩 17 → **20**, 간격 12로 디자인 시스템 카드와 일치.
- `Button` 높이 50 → **52**, 반경 15 → **16**. 어두운 히어로 위에서 쓰는 `tone="onDark"`(흰 배경·검은 글자)를 추가했습니다.
- `Label`의 줄 간격을 20px 이상 1.3, 그 미만 1.47로 고정해 화면마다 행 높이가 들쭉날쭉하지 않게 했습니다.

## 1. 하단 탭 바 — 컬러 이모지 제거, 모노크롬 아이콘 (`src/ui-v2/Icons.tsx`, `src/App.tsx`)

- v0.3.5의 `🏠 📋 🔍 📈 👤` 이모지는 플랫폼마다 색과 모양이 달라 `form.`의 흑백 미학과 충돌했습니다.
- `TabIcon`은 22px 상자 안에 선 굵기 **1.8**로 그리는 순수 `View` 도형입니다.
  - `home`: 지붕 두 변(±45° 회전 막대) + 아래가 열린 몸체 프레임
  - `workout`: 점 + 줄 세 개(루틴 목록)
  - `library`: 원 + 45° 손잡이(돋보기)
  - `progress`: 기준선 + 높이가 다른 막대 세 개
  - `settings`: 머리 원 + 어깨 아치
- 색은 활성 `palette.text`, 비활성 `palette.secondary`. 활성 탭은 배경 알약(`colors.soft`)으로 표시합니다.
- `App.tsx`의 `tabs` 배열은 `[key, label]` 두 칸으로 줄었고, 탭 항목 간격 2 → 3, 반경 18 → 16.
- 접근성 라벨(`오늘`, `루틴`, `운동도감`, `기록`, `내 정보`)과 `tab` 역할, `selected` 상태는 그대로입니다
  (`scripts/runtime-journeys.py`의 `wait_for("오늘")`, `tap_exact("운동도감")`이 이 라벨을 씁니다).

## 2. 집중 운동 화면 (`src/ui-v2/FocusedWorkout.tsx`)

- **휴식 행 2단 정리**: 왼쪽에 `휴식 / 0:45`(라벨 micro + 값 subheading, tabular-nums), 오른쪽에 `−15초` `+15초` 필 버튼.
  둘째 줄에 `건너뛰기`(휴식 중일 때만)와 `휴식 프리셋 ▾`, 맨 오른쪽에 `접기 ▾`.
- **`▾`의 의미를 명시**: v0.3.5의 정체불명 `▾`를 `휴식 프리셋 ▾` 필 버튼으로 바꿨습니다.
  누르면 `60초·90초·120초·추천 N초` 프리셋과 직접 입력 필드가 한 줄로 열립니다(높이 36, 반경 999, 선택 시 테두리 본문색).
  패널을 접는 동작은 `접기 ▾` 필 버튼(`accessibilityLabel="컨트롤 숨기기"`)으로 분리했습니다.
- **세부 설정**: 왼쪽에 작게 떠 있던 `세부 설정 열기 ▾`를 카드 전체 폭 테두리 바(높이 44)로 바꾸고,
  라벨과 `▴/▾`를 양끝에 두었습니다. 펼치면 훈련 목적 3개가 같은 폭 필로 놓입니다.
  휴식 입력은 프리셋 줄로 옮겨 같은 항목이 두 곳에 나오지 않게 했습니다.
- `+ 세트 추가` / `전체 운동 목록`은 반투명 회색 채움 대신 **1px 테두리 반반 폭** 버튼으로 통일했습니다.
- 순서·대체·슈퍼세트·원판 동작은 높이 36 필 버튼, RPE 빠른 선택(7·8·9·10)과 직접 입력도 36 높이 알약으로 맞췄습니다.
- 추천 문구는 회색 서브카드(반경 14) + `적용` 필로 묶었습니다.
- 접힌 컨트롤 바(`컨트롤 열기 ▴`, `세트 완료`)는 그대로 두되 반경·높이만 시스템 값에 맞췄습니다.

## 3. 루틴 준비 · 전체 운동 목록 (`src/App.tsx`)

- **상단 액션 좌측 쏠림 해소**: `운동 시작`/`준비 닫기`, `일시정지`/`운동 종료`를 각각 `flex: 1` 반쪽 컨테이너에 넣어
  화면 폭을 정확히 양분합니다(`s.headerActions`). 운동 이름과 `진행 중 · 0:03` 상태는 아래 줄에서
  이름(flex) + 상태 알약(`s.statusPill`)으로 나눴습니다. 상태 문구 자체는 바꾸지 않았습니다.
- **운동 카드 액션 툴바**: 테두리 없이 공중에 뜬 `↑ ↓ 대체 슈퍼세트 원판`을 같은 규격의 필 버튼
  (`Pill`: 높이 36·반경 999·1px 테두리)으로 바꿨습니다. 접근성 라벨(`${운동명} 순서 위로` 등)은 유지했습니다.
- **추천 배너**: 4줄 장문 + 오른쪽 세로 중앙에 떠 있던 `참고`를, 회색 서브카드 안에서
  문구(flex)와 `적용/참고` 필이 세로 중앙으로 나란히 서는 구조로 바꿨습니다.
- **세트 표 정렬**: 헤더와 입력 행이 같은 열 폭을 공유합니다 —
  번호 `28`, 중량 `flex`, 횟수 `flex`, 완료 `48`, 간격 `8`. 헤더 글자는 각 입력칸 위에 **가운데 정렬**되어
  `kg`·`횟수` 라벨이 입력 박스 중심축과 맞습니다. 직전 기록 힌트는 번호 열(36)만큼 들여씁니다.
- **세트 하단 컨트롤**: `일반 ↻` `세트 삭제` `[RPE]`를 모두 높이 36·반경 999 필 규격으로 통일하고
  필드 아래(36 들여쓰기)에 한 줄로 붙였습니다. RPE 입력도 같은 높이의 알약 입력입니다.
- 카드 제목은 `운동명 ⓘ`(17) + 둥근 삭제 버튼(34), 슈퍼세트 표시는 카드 상단 배지로 정리했습니다.

## 4. 운동도감 (`src/App.tsx`)

- **빠른 보기 3열**: `모든 운동 / 최근 한 운동 / 즐겨찾기`를 `Segmented`(같은 폭 3분할, 회색 트랙 안 흰 세그먼트)로 바꿔
  2+1 줄바꿈을 없앴습니다. `★` 글자 대신 라벨만 남겨 모노크롬 톤을 지켰습니다.
- **보조근 포함 토글**: `보조근 포함 ✓` 텍스트를 테두리 알약(켜짐: 강조색 배경·테두리, 꺼짐: 회색)으로 바꾸고
  `switch` 역할과 `보조근 포함`/`주동근만` 라벨을 유지했습니다.
- **근육 모형으로 찾기**: 작은 글자 링크에서 전체 폭 테두리 바(높이 44, 오른쪽 `▾/▴`)로 바꿨습니다.
- 필터 그룹 간격 7 → 10, 칩 높이 44 → 36·반경 20 → 999로 줄여 `부위`·`타깃 근육`·`장비`가 한눈에 들어오게 했습니다.

## 5. 운동 기록 (`src/App.tsx`, 공통 컴포넌트 `MetricTile`·`GoalProgress`)

- **최근 운동 요약 카드**를 위계 순으로 다시 쌓았습니다.
  1) 제목(17) + 날짜(12) + `N세트 · M분` 알약 → 2) 볼륨·직전 대비 타일 두 개 → 3) PR 배지 줄 → 4) 주간 목표 블록.
- **지표 타일**: 이전에는 `Glass`를 padding 14로 재사용해 값이 적으면 세로로 텅 비었습니다.
  `MetricTile`(최소 높이 78, 좌우 14·상하 12, 라벨 micro + 값 heading + 단위 caption)로 바꿔 두 타일 높이가 항상 같습니다.
- **주간 목표**: 따로 떨어져 있던 `이번 주 n회 · 목표 m회` 텍스트와 진행 바를 `GoalProgress`로 묶어
  라벨 줄(`이번 주 목표` / `1/3회`) 바로 아래에 6px 진행 바가 붙게 했습니다. 홈의 주간 목표가 이 컴포넌트를 씁니다.
  (같은 목표를 두 탭에서 반복하지 않도록 `기록` 탭에서는 이 블록을 뺐습니다 — 9.1 참고.)
- `전체 운동`·`최고 추정 1RM` 타일도 같은 규격입니다.
- 히스토리 줄, 성장 그래프 칩은 그대로 두고 크기·간격만 시스템 값으로 맞췄습니다.

## 7. 접근성 라벨 — 테스트와의 정합

`scripts/runtime-journeys.py`와 `tests/ios/WorkoutJourney.swift`가 찾는 이름은 그대로 두었습니다.

- 탭: `오늘` `루틴` `운동도감` `기록` `내 정보`
- 준비/진행: `운동 시작` `준비 닫기` `일시정지` `계속하기` `운동 종료` `일시정지됨 · …` `준비 중 · 0:00`
- 세트: `${운동명} N세트 중량/횟수/완료`, `+ 세트 추가`, `세트 완료`, `2번째 세트`, `전체 운동 목록`
- 집중: `컨트롤 숨기기` `컨트롤 열기` `휴식 15초 줄이기/늘리기` `건너뛰기` `세부 설정 열기/접기`
- 도감: `타깃 근육` `보조근 포함` `근육 모형으로 찾기` `도감 근육 모형 · 앞면/배면`, 이전 `운동 목록`
- 기록: `최근 6주 운동 볼륨`, `이번 주 근육 볼륨`, `배면`, `화면 스타일`, `Liquid Glass 효과`, `휴식 시간 늘리기/줄이기`
- `휴식 프리셋 열기/접기`, `휴식 60/90/120초`, `추천 휴식 적용`, `다음 세트로`를 새로 추가했습니다(기존 이름과 충돌 없음).
- **한 요소에 글자 두 개를 넣을 때는 반드시 `accessibilityLabel`을 함께 줍니다.** 0.3.6 첫 CI 실행에서 `근육 모형으로 찾기 ▾` 처럼
  제목과 화살표를 각각 `Label`로 넣자 Android 접근성 이름이 `근육 모형으로 찾기, ▾`로 합쳐져, 정확히 같은 이름을 찾는
  `scripts/runtime-journeys.py`의 `tap_exact`가 실패했습니다. 토글에 제목과 같은 `accessibilityLabel`을 주어
  `근육 모형으로 찾기` / `근육 모형 접기`로 정확히 노출되게 고쳤습니다(같은 규칙을 `Pill`·`세부 설정`·`휴식 프리셋`에도 적용).

## 8. 실사용 편의성 4가지 (모리 님 추가 지시)

### 8.1 iOS 숫자 키패드 위 `완료` 툴바 — `src/App.tsx`, `src/ui-v2/FocusedWorkout.tsx`

- 숫자 키패드에는 기본 완료 키가 없어 무게·횟수·RPE를 넣은 뒤 화면을 눌러 키보드를 닫아야 했습니다.
- `Main` 트리에 `InputAccessoryView nativeID="form-keyboard-done"`를 한 번만 두고, `완료`를 누르면 `Keyboard.dismiss()`가 실행됩니다.
  막대는 카드와 같은 선·배경색을 쓰고 높이 44, 글자는 강조색입니다.
- 부착 대상: `Numeric`(무게·횟수·휴식초), `RpeInput`, `numeric` 입력(인바디 등), 집중 운동의 중량·횟수·RPE·휴식 입력.
- **Android·테스트 가드**: `Platform.OS === 'ios'`일 때만 `inputAccessoryViewID`를 넘기고 컴포넌트도 iOS에서만 렌더합니다.
  Android는 IME의 기본 완료 동작을 그대로 쓰므로 에뮬레이터 여정(`scripts/runtime-journeys.py`)의 탭·스와이프 좌표가 바뀌지 않습니다.

### 8.2 휴식 종료 햅틱을 한 번만 — `src/App.tsx`

- 0.3.5에도 `restEndsAt`이 지나면 `Haptics.notificationAsync(Success)`를 울리는 코드가 있었지만,
  상태 커밋 전 1초 타이머가 여러 번 돌면 같은 휴식에 진동이 겹칠 수 있었습니다.
- `restRung` ref에 마지막으로 울린 종료 시각을 기록해 **휴식 하나당 정확히 1회**만 울립니다.
  휴식이 없으면 ref를 비워 다음 휴식은 다시 울립니다. `.catch(() => {})`로 햅틱 미지원 기기·권한 문제에서도 조용히 넘어갑니다.

### 8.3 모든 세트를 마친 종목 카드 자동 접기 — `src/App.tsx`

- 전체 운동 목록에서 한 종목의 세트를 모두 완료하면 그 카드는 `이름 + N/N세트 완료 배지 + 펼치기 ▾`만 남는 컴팩트 카드로 접힙니다.
  카드가 길어 다음 종목이 화면 밖으로 밀리는 문제를 줄이기 위해서입니다.
- `expandedDone` 상태(종목 id → 펼침 여부)로 관리하며, `펼치기` 필을 누르면 원래 카드가 그대로 돌아오고
  세트·도구·메모를 계속 고칠 수 있습니다. 다시 접으려면 툴바의 `접기` 필을 누릅니다.
- 접힘 조건은 `!preparing && 세트 수 > 0 && 완료 세트 수 === 세트 수 && !expandedDone[id]`입니다.
  **준비 화면에서는 절대 접히지 않습니다**(세트를 미리 입력하는 화면이므로).
- 접근성 라벨: `${운동명} 펼치기`, `${운동명} 접기`.

### 8.4 지난 기록 원탭 채우기 — `src/workout-features.mjs`, `src/App.tsx`

- 새 순수 함수 `applyPreviousSets(sets, previous)`:
  - 완료한 세트는 그대로 두고 **미완료 세트에만** 직전 세션 같은 순번의 무게·횟수를 넣습니다.
  - 직전 세션이 세트 수가 적으면 마지막 값을 반복하고, 직전 기록이 없으면 배열을 그대로 돌려줍니다(원본 불변).
  - 채운 세트는 `edited: true`로 표시해 훈련 목적 추천이 다시 덮어쓰지 않게 합니다.
- 이전 기록이 있는 종목 카드 툴바에 `지난 기록 채우기` 필(`accessibilityLabel="${운동명} 지난 기록 채우기"`)을 두었습니다.
- **테스트** — `tests/workout-features.test.mjs`에 2개 추가(완료 세트 보존·순번 매칭·마지막 값 반복·원본 불변·빈 입력).

## 9. 사용자 입장 중복 정리 (모리 님 추가 확인 지시)

### 9.1 `기록` 탭의 주간 목표 중복 제거 — `src/App.tsx` `progress()`

- `오늘` 탭이 이미 `이번 주 운동` 카드에서 목표 진행 바(`이번 주 목표 1/3회`)와 누적 볼륨을 보여 줍니다.
- `기록` 탭의 `최근 운동 요약` 카드에서는 `1/3회` 표기와 주간 진행 바를 빼고 **그 세션의 성과**만 남겼습니다:
  날짜, `N세트 · M분` 알약, 총 볼륨·직전 대비 타일, PR 배지.
- `GoalProgress` 컴포넌트는 홈에서만 사용합니다. `sessionSummary`의 `weekCount/weekGoal`은 다른 화면·알림에서 계속 쓰입니다.

### 9.2 `내 정보 > 내 데이터`의 인바디 진입 중복 제거 — `src/App.tsx` `settings()`

- 인바디 조회·입력은 `기록` 탭(인바디·체성분 카드 → `추이 보기`)에서 바로 됩니다.
- `내 정보 > 내 데이터`에서 `인바디·체성분 기록` 버튼을 빼고, 그 자리에 `인바디·체성분은 기록 탭에서 조회·입력합니다.` 안내만 남겼습니다.
  이 섹션은 **백업 내보내기·가져오기·앱 기록 삭제**라는 데이터 관리에만 집중합니다.
- `scripts/runtime-journeys.py`·`tests/ios/WorkoutJourney.swift`에서 이 버튼을 누르는 곳은 없음을 확인했습니다(라벨 검색 0건).
  iOS 테스트가 찾는 `백업 파일 내보내기` 버튼은 그대로입니다.

### 9.3 집중 운동 ↔ 전체 목록 왕복 — `src/ui-v2/FocusedWorkout.tsx`

- 집중 운동 메인 카드에 현재 세트의 **중량·횟수 입력과 ± 스테퍼가 항상 보입니다**(세부 설정·프리셋 안에 숨기지 않음).
  숫자 하나를 고치려고 `전체 운동 목록`으로 나갔다 돌아올 필요가 없습니다.
- 같은 카드에서 세트 종류 전환, RPE, 세트 삭제, 메모, 다음 세트 선택까지 되고,
  `설정`에 접어 둔 것은 훈련 목적과 휴식 프리셋뿐입니다.
