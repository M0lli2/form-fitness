# WWIT 참고 UI 업데이트 — 2026-11-19

[WWIT 플랜핏 아카이브](https://wwit.design/2023/07/24/planfit/)와 [Planfit 공식 소개](https://planfit.ai/ko)의 홈에서 운동을 고르고 기록으로 넘어가는 흐름을 참고했습니다.

- 홈 상단에서 추천 루틴과 포함 운동 수를 확인합니다. 진행 중인 세션이 있으면 해당 운동 이름과 이어하기가 표시됩니다.
- 주간 카드에 운동 횟수, 목표 진행률, 요일별 완료 상태, 누적 볼륨을 모았습니다. 오늘과 완료 상태를 화면 읽기 기능으로도 확인할 수 있습니다.
- 홈에서 내 루틴 전체 보기와 운동도감으로 이동할 수 있습니다. 하단 메뉴 전환 시 해당 화면의 상단부터 표시합니다.
- 최근 운동도감, 운동 추가 전 자세 확인, 3D 가이드 8종, 라이트·다크·Glass 설정이 같은 소스에 포함됩니다.

로컬 검증에서 테스트 30개와 설정·브리지 검사, 소스 구문 검사가 통과했습니다. 이 결과는 네이티브 빌드와 실기기 검증에 해당하지 않습니다. APK 제공 버전은 [설치 안내](INSTALL.md)를 확인하세요.
