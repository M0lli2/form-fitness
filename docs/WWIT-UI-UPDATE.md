# 11월 19일 FORM UI 업데이트

[WWIT 플랜핏 아카이브](https://wwit.design/2023/07/24/planfit/)와 [Planfit 공식 소개](https://planfit.ai/ko)의 운동 선택, 기록, 분석 흐름을 참고했습니다. FORM의 화면 구성에 같은 글자 계층과 조작 규칙을 적용했습니다.

| 화면 | 변경 |
|---|---|
| 홈 | 진행 중 운동, 추천 루틴, 주간 목표와 달력 상태 |
| 루틴·운동 | 자유 운동, 루틴 생성·편집, 세트 수정 버튼의 터치 영역 및 포커스 화면 버튼 |
| 운동도감·자세 | 운동명·장비·부위 검색, 부위·장비 필터, 3D 지원 운동 식별, 자세 단계, 운동 추가 목록 |
| 기록·인바디 | 운동 이력과 체성분 이동, 읽기 가능한 그래프와 접근성 값, 최근 체중과 측정 기록 |
| 설정·입력 | 라이트·다크·시스템, 독립 Liquid Glass 스위치, 연결 동작, 기록 백업, 키보드와 하단 시트 |

30개 로컬 테스트, 프로젝트 설정 검사, 타입 검사, Android·iOS Hermes 번들 내보내기가 통과했습니다. 최신 Android APK의 서명과 패키지 내용을 검사했습니다. [설치 및 배포 안내](INSTALL.md)
