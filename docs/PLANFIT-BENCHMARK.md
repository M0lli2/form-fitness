## 관찰과 제품 결정
Planfit 공개 화면은 운동 목록과 한 운동에 집중하는 진행 화면을 분리한다. FORM도 '오늘 운동 구성 → 운동별 집중 기록 → 휴식 → 다음 세트/운동 → 완료 요약' 순서를 채택한다. 상단은 경과 시간·현재 운동 번호, 중앙은 가이드와 세트 입력, 하단은 현재 동작의 주 버튼으로 구성한다.

기존 FORM 초안의 6개 하단 탭과 큰 홍보 문구는 축소한다. 일상 탐색은 오늘/루틴/기록/내 정보 4개로 정리하고 운동법은 루틴의 검색·상세에서 접근한다. 진행 중에는 일반 탭바 대신 운동 목록·휴식·세트 완료 컨트롤을 사용한다. 이 배치는 FORM의 설계 선택이며 Planfit 최신 메뉴와 완전히 동일하다는 의미가 아니다.

## 기능 대응표
| 흐름 | 확인된 제품 기능 | FORM 작업 |
|---|---|---|
| 시작 | 목표·수준·장비 기반 플랜 | 프로필 입력/장비 필터와 플래너 구현 필요 |
| 준비 | 루틴/운동 목록·세트 편집 | 기존 로컬 소스 회수 후 통합 |
| 진행 | 한 운동 가이드·세트 기록 | src/ui-v2/FocusedWorkout.tsx 작성 |
| 휴식 | 타이머·다음 운동 이동 | 집중 화면 표시 구현, 백그라운드 서비스 통합 필요 |
| 완료 | 운동 내역·시간·캘린더 | 기존 로컬 기록 로직 회수 후 연결 |
| 운동법 | 영상·자세·팁 | 자체/라이선스 확보 콘텐츠 필요. 경쟁사 영상 미포함 |
| 개인화 | AI 추천 및 코칭 | 모델·학습 데이터에 접근하지 못함. 동일 결과 보장 불가 |
| 계정/소셜 | 기록 공유·커뮤니티 | 서버·권한·운영 정책 개발 필요 |
| 추가 요구 | 인바디·워치·건강 연동 | 로컬 초안 존재 이력, 원격 등록/실기기 확인 미완료 |

## 시각 방향
무채색을 유지하고 성공/오류에만 의미 색을 사용한다. Planfit 브랜드, 로고, 영상, 앱 내 이미지는 번들하지 않는다. 제품 비교에는 링크만 남긴다. 유리 효과는 Apple의 native regular material을 탐색/조작층에만 적용한다. 기록표와 수치는 불투명 배경을 유지한다.

1. 홈/루틴 준비/집중 운동/완료 기록 시안 승인.

3. 실제 네이티브 스크린샷과 시안 대조.
4. 키보드·큰 글씨·한 손 입력·뒤로 가기·기기 회전 검증.
