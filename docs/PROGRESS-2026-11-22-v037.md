# Form 0.3.7 작업 기록 — Apple 수준 곡률·비율·텍스트 완성도 (2026-11-22)

모리 님의 피드백(#15426, #15450)으로 0.3.6 화면 전체를 다시 뜯어 고친 릴리스입니다.

> "내가 원하는건 애플에선 변태적으로 비율과 조화 일관된 동일한 곡률등 디자인의 완벽함을 요하잖아?"
> "곡률뿐만아니라 박스들의 배치와 구성요소들도 다 비율과 배치가 조화롭고 통일감있게, 텍스트등등 다 완벽해야힌다는거야"

- 기준 커밋: `main` `044cf4b` (v0.3.6)
- 릴리스 브랜치: `release/v0.3.7` (중간 프리뷰 브랜치 없음)
- 새 파일: 없음. 기존 디자인 시스템 파일(`tokens.ts`, `Primitives.tsx`, `Controls.tsx`)과
  화면 2개(`App.tsx`, `FocusedWorkout.tsx`), 순수 함수 1개(`workout-features.mjs`)만 고쳤습니다.
- 새 네이티브 의존성: **없음**.

| 축 | 0.3.6 | 0.3.7 |

## 1. `src/ui-v2/tokens.ts` — 값이 나오는 유일한 곳

- **반경 사다리**: `radius = {pill:999, sheet:32, nav:30, card:24, inner:16, small:12}`.
  화면 코드는 이 여섯 값만 참조합니다. 카드 안 서브카드·입력·버튼은 `inner`, 그 안의 작은 사각형은 `small`.
- **동심원 헬퍼**: `concentric(outer, inset, floor=8) = max(8, outer − inset)`.
  - 하단 탭 바 `nav 30` − 내부 여백 `6` → 선택 캡슐 `24` (`geometry.navItemRadius`)
  - 세그먼트 트랙 `inner 16` − 여백 `4` → 활성 세그먼트 `12` (`geometry.segmentItemRadius`)
- **4pt 그리드**: `space = {xs:4, sm:8, md:12, lg:16, xl:20, xxl:24}`,
  `height = {chip:36, icon:36, control:44, field:48, button:52}`.
- **Squircle**: `squircle = {borderCurve:'continuous'}`. React Native `ViewStyle`에 `borderCurve`가
  타입으로 있으므로 `...squircle`로 그대로 펼칩니다. Android는 이 속성을 무시하고 같은 반경의 원형 곡률을 씁니다.
- `geometry`는 기존 이름을 유지한 채 새 사다리에서 파생시켰습니다(다른 파일이 깨지지 않게).
  `navRadius`, `navItemRadius`, `segmentRadius`, `segmentItemRadius`, `sheetRadius`, `cardPadding`,
  `cardGap`, `tightGap`, `iconButton`이 새로 생겼습니다.

## 2. 공용 컴포넌트 (`Primitives.tsx`, `Controls.tsx`, `theme.tsx`)

- `Surface`: `role='navigation'`이면 반경 30(탭 바), 그 외 24. 재질 레이어(GlassView·BlurView·단색)와
  테두리까지 **같은 shape 객체**를 써서 곡률이 어긋나지 않습니다. 모든 표면에 `borderCurve:'continuous'`.
- `Action`: 높이 52 · 반경 16 · 좌우 여백 20. 글자는 한 줄 고정.
- `Pill`: 높이 36 · 반경 999 · 좌우 12, 글자 한 줄(`numberOfLines=1`) — 좁은 칸에서 줄 수가 달라지지 않습니다.
- `ToolRow`(신규): 자식을 **같은 폭 칸**으로 감싸는 줄. 4개든 2개든 칸 폭이 정확히 같아
  `3+2`처럼 한쪽이 텅 비는 줄바꿈이 구조적으로 불가능합니다.
- `Segmented`: 트랙 16 · 여백 4 · 활성 칸 12(동심원). 칸 높이 36.
- `MetricTile`: 최소 높이 80 · 여백 16/12 · 반경 16. 단위는 `3회`처럼 세는 단위면 숫자에 붙이고
  `0 kg`·`12 %`처럼 재는 단위면 한 칸 띄웁니다(`metricValue`의 gap 제거 + 단위별 marginLeft).
- `GoalProgress`: 라벨 줄 + 8px 아래 6px 바(반경 3) — 트랙과 채움의 곡률이 같습니다.
- `Glass`/`Button`(`src/theme.tsx`): 카드 24·여백 20·간격 12, 버튼 52·반경 16, 둘 다 squircle.

## 4. 운동 준비·진행 화면 (`App.tsx` `workout()`)

### 4.1 도구 줄 — 3+2 줄바꿈 제거
- 0.3.6: `↑ 위로` `↓ 아래로` `대체` / `슈퍼세트` `원판`(또는 `지난 기록 채우기`까지) → 3+2 비대칭.
- 0.3.7: **두 줄 고정**
  - 1줄: `↑` `↓` `대체` `원판` — 4칸 등분(폭 54pt @320)
  - 2줄: `슈퍼세트`(또는 `슈퍼세트 해제`) `지난 기록` — 2칸 등분(폭 116pt @320)
- 접근성 이름은 그대로입니다(`${운동명} 순서 위로`, `${운동명} 대체 운동`, `${운동명} 지난 기록 채우기` 등).
  화면에 보이는 글자만 짧게 줄였습니다(`지난 기록 채우기` → `지난 기록`).
- 카드에서 세트를 모두 마친 뒤의 `접기`는 도구 줄에서 빼 **카드 머리말의 아이콘 버튼**(▴)으로 옮겼습니다.
  도구 줄이 항상 4칸/2칸으로 유지되게 하기 위해서입니다(접근성 이름 `${운동명} 접기` 유지).

### 4.2 추천 배너 — 단어 중간 줄바꿈 제거
- 0.3.6: `근비대(75% 1RM) · 첫 기록입니다. 8~12회 × 3세트 · 휴식 …`를 2줄로 자르면서 `첫 기록입 / 니다.`로 끊겼습니다.
- 0.3.7: `recommendationLines(rec)`(순수 함수)가 같은 객체에서 두 조각을 만듭니다.
  - 배지(좌상단): `근비대 75% 1RM`
  - 본문(2줄 고정): `8~12회 × 3세트 · 휴식 90초 · 첫 기록` / 이전 기록이 있으면 `이전 추정 1RM 82.5kg 기준`,
    체성분만 있으면 `체성분 기반 초기 추정`
  - `적용`/`참고` 필은 배지와 같은 줄 오른쪽.
- 인바디 안내 문장은 배너에서 뺐습니다(설정 화면·훈련 목적 카드에 그대로 남아 있습니다).

### 4.3 세트 하단 3필 — 균등 분배
- `일반 ↻` `세트 삭제` `[RPE]`를 카드 폭 전체의 **3등분 칸**(`s.setMetaCell = flex:1`)에 넣었습니다.
  0.3.6은 36pt 들여쓰기 + 내용 폭만큼의 필이라 오른쪽이 비었습니다.
- RPE 입력은 칸 폭을 100%로 채웁니다.

### 4.4 그 밖의 규격
- 상단 액션 두 개는 항상 반반(`gap 12`), 상태 알약은 높이 28·반경 999.
- 입력·체크: 반경 16(입력 48, 체크 48×48), 필 36, 보조 컨트롤 44.
- 카드 머리말 삭제 버튼 34 → 36(아이콘 높이 4pt 배수).

### 5.2 컨트롤 패널 — 네 줄로 축소
- 0.3.6: 휴식 줄 / 도구 줄 / 세트 완료 / `+ 세트 추가`·`전체 운동 목록` / `세부 설정`·`다음 세트` → 5줄.
- 0.3.7: 휴식 줄 / 도구 줄 / **세트 완료** / `+ 세트 추가`·`전체 운동 목록` → 4줄.

- 접힌 상태(`컨트롤 열기`)와 접근성 이름은 그대로입니다. `+ 세트 추가`는 접었을 때 사라져야 한다는

### 5.3 도구 줄
- 스크롤 맨 아래 순서·대체·원판을 4칸, 슈퍼세트를 2칸 줄로 나눠 3+2 줄바꿈을 없앴습니다.

- 추천 배너는 같은 `recommendationLines` 결과를 받아 배지 + 처방 한 줄로 보여 줍니다.

## 6. 운동 기록 (`App.tsx` `progress()`)

## 7. 텍스트 완결성

- **크기**: 화면 코드의 `size={12}`(39곳) → 13, `14` → 15, `35` → 36, 모달 운동명 `24` → 22.
  남은 예외는 브랜드 표기 `form.`(24)와 글자 도형(`×`, `▴`, `★`)뿐입니다.
- **마침표**: 제목·라벨·배지·수치는 마침표 없음, 설명 문장은 모두 `다.`로 끝냅니다.
  유일하게 빠져 있던 `첫 운동을 추가하세요` → `첫 운동을 추가하세요.`
- **단위**: `0 kg`·`12 %`(재는 단위, 한 칸), `3회`·`3세트`·`6개`(세는 단위, 붙임).
- **한 줄 고정**: 필·칩·배지·탭 라벨은 `numberOfLines=1`로 줄 수가 칸마다 달라지지 않습니다.

## 8. 검증

### 8.1 버전 표기 동기화 (`wearos/app/build.gradle.kts`, `scripts/check-project.mjs`)

- Wear OS 모듈은 `versionName`을 `app.json`에서 읽지 않고 손으로 적습니다. 0.3.6 릴리스 기록에는
  `0.3.6`이 남아 있어, 0.3.7 첫 릴리스 시도에서 `Build and verify the paired Wear OS package` 단계가
  `aapt dump badging`의 `versionName='0.3.6'`과 `app.json`의 `0.3.7`이 달라 실패했습니다.
- `wearos/app/build.gradle.kts`의 `versionName`을 `0.3.7`로 올리고(`versionCode` 6은 유지),
  `scripts/check-project.mjs`가 `package.json`·`app.json`·Wear OS `versionName`/`versionCode`를
  서로 대조하도록 검사를 추가했습니다. 다음 릴리스부터는 이 불일치가 `Source checks`에서 먼저 잡힙니다.

### 8.3 스크린샷 자체 검수에서 잡아 고친 것

- **컨트롤 패널 마지막 줄 잘림**: `ToolRow` 칸 안의 버튼이 자기 `flex:1`을 그대로 갖고 있어 줄 높이가 15pt로 접혔고,
  `+ 세트 추가`·`전체 운동 목록`이 탭 바 아래로 잘렸습니다. 칸이 폭을 맡고(`flexBasis:0`·`flexGrow:1`·`stretch`)
  버튼은 자기 최소 높이를 쓰게 고쳐 44pt로 온전히 보이게 했습니다(캡처로 재확인).
- **`아래로` 잘림**: 4칸 줄에서 세 글자 라벨이 54pt 칸에 들어가지 않아 `아…`로 잘렸습니다. 순서는 한 글자 아이콘
  `↑`·`↓`로 두고 뜻은 접근성 이름(`${운동명} 순서 위로`·`아래로`)이 전합니다.
